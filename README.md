## 便宜VPS怎麼挑：虛擬化技術和線路，比價格更該先看

同樣掛著「便宜」兩個字，兩台 VPS 的實際體驗可能差很遠。下手前先看兩件事：虛擬化技術、線路類型，然後才是價格。

虛擬化技術的優先順序是 KVM > Xen > OpenVZ，這個排序基本也是價格從高到低的排序。KVM 最接近獨立伺服器的使用體驗，相容性和隔離性都更好；低價帶偶爾會遇到 OpenVZ 機型，限制多，除非價格低到離譜，否則優先 KVM。

面向中國大陸的連線，線路排序記住這一條就夠：**CN2 GIA > AS9929 > AS4837 > CN2 GT**。機房距離的大方向也簡單：國內機房最好，其次是香港、台灣，再次是日本、韓國、新加坡，美國等更遠的機房排在最後。

這也解釋了行情表裡的一個規律：同樣三十多美元一年，香港、東京的機型月流量只給到 1.5TB，美國機型能給到 4–5TB。優質線路的頻寬成本高，商家在流量上自然摳一點。所以「香港日本延遲低但流量少、美國流量大但延遲高」這筆帳，下單前要先算清楚。

還有一個藏在參數表裡的細節：低價年付方案的 CPU 經常標註 Fair Share（共享核心），實際效能會隨宿主機負載浮動。對資源保障有要求的，找明確標了 Dedicated（獨享）的方案，例如 AlphaVPS 的年付機型就標明了 4GB 獨享記憶體。同樣是便宜，資源保障方式不一樣。
